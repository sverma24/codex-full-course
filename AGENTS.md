# My Library Books

- Open `index.html` directly in your browser. No server or dependencies are required.
- Run `npm test` from the project root. It uses Node.js's built-in test runner.
- `books.js` holds the library's rules. Keep it free of page and DOM code.
- `app.js` holds the page code.
- Change how the page looks only when the user asks.
- For every bug, first add a test and verify it fails. Then fix the bug and verify the test passes.
